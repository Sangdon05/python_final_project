# Python 기초 과제

---

## 📝 과제 소개

파이썬 기초 문법을 바탕으로 사용자와 상호작용하는 콘솔 프로그램(CLI)을 개발하는 프로젝트입니다. 그동안 배운 파이썬 문법을 활용하여 **'도서 관리 시스템'** 을 구현하게 됩니다.

`input()` 함수 기반의 대화형 메뉴를 설계하고 도서 데이터의 등록, 검색, 대여 프로세스 로직을 직접 작성합니다. 이 과정을 통해 데이터 특성에 맞는 자료구조 선택 방법, 객체지향 설계, 패키지 매니저 `uv`를 활용한 가상환경 구축 등 프로그램 개발에 필요한 전반적인 과정을 익힐 수 있습니다.

---

## 🚩 과제 목표

- `input()`과 반복문으로 도서 관리 CLI 시스템을 구축할 수 있다.
- `uv` 도구로 가상환경을 구축하고 VS Code·주피터 노트북과 연동할 수 있다.
- 객체지향(OOP) 기법을 활용해 확장 가능한 도서 모델을 설계할 수 있다.
- 리스트·딕셔너리·집합을 선택해 데이터를 효율적으로 관리할 수 있다.
- 조건문과 반복문을 조합해 검사, 검색, 필터링 기능을 구현할 수 있다.
- 코드를 패키지 및 모듈 구조로 분리해 재사용성을 높일 수 있다.
- `try-except`와 디버깅으로 실행 오류를 진단하고 수정할 수 있다.

## 🔝 최종 결과물 제출 형식

### 제출 파일명

```
python_final_project_[수강생이름].zip
```
(프로젝트 전체 디렉터리를 포함하여 압축된 파일)

### 필수 내부 구조

```
python_final_project_[수강생이름]/
├── models/                    # 도서 객체 관련 모듈 폴더
│   ├── __init__.py
│   ├── base_book.py           # 상위 도서 클래스
│   └── specialized_books.py   # 하위 도서 클래스 (단행본, 전자도서 등)
├── utils/                     # 공통 유틸리티 함수 폴더
│   ├── __init__.py
│   └── helpers.py             # 입력 검증 및 포맷팅 등
├── main.py                    # CLI 메뉴 루프 및 프로그램 진입점
├── pyproject.toml             # uv 프로젝트 가상환경 설정 파일
└── uv.lock                    # 의존성 고정 락 파일
```

## 1. 도서 관리 시스템 구현

### 1️⃣ 구현 내용

#### ✅ [필수] 구현 내용

| 구현 내용 | 설명 |
|---|---|
| **환경 구성 및 패키지 모듈화** | `uv` 도구를 이용해 독립된 가상환경을 생성하고 의존성을 lock 파일로 지정합니다. 구조 모델(`models/`), 유틸리티 함수(`utils/`), 메인 실행부(`main.py`)로 폴더를 나누어 하나의 패키지 구조로 격리하고 VS Code 환경에서 메인 스크립트가 정상 작동함을 확인합니다. |
| **대화형 콘솔 메뉴(CLI) 구축** | `main.py` 실행 시 `while` 문과 `input()` 함수를 사용하여 사용자 인터페이스(1. 도서 등록, 2. 전체 도서 조회, 3. 도서 검색, 4. 대여/반납 처리, 5. 종료)를 화면에 띄우고, 입력값에 따라 해당 로직이 실행되도록 제어 흐름을 설계합니다. |
| **객체지향 구조화** | 기본 도서 속성(도서명, 저자, ISBN 등)을 지닌 상위 클래스를 정의하고, 이를 상속받는 하위 클래스(일반 단행본, 전자 도서 등)를 구성합니다. 프라이빗 변수를 활용해 데이터 직접 접근을 제어하고, 상세 내용을 표현하는 메서드를 오버라이딩하여 구현합니다. |
| **대여/반납 로직 구현 및 자료구조** | 개별 도서 상세 정보(딕셔너리), 고유 식별 번호 목록(집합)을 활용하여 도서를 관리합니다. 특정 도서의 ISBN을 입력받아 대여 가능 여부를 확인하고 상태를 전환하는 흐름 제어를 구현합니다. 중복 ISBN 입력이나 공백 등 유효하지 않은 입력은 차단하며, 자료구조 선택 근거를 주석으로 명시합니다. |
| **기본 예외 방어** | 콘솔로 숫자를 입력받아야 하는 메뉴 선택 등에서 문자 입력으로 발생할 수 있는 타입 오류(`ValueError` 등)에 프로그램이 강제 종료되지 않도록 `try-except` 예외 처리 문법을 적용합니다. |

#### 🔥 [심화] 구현 내용

| 구현 내용 | 설명 |
|---|---|
| **대여 이력 관리 및 콘솔 통계 연산 (튜플/리스트 활용)** | 도서가 대여·반납될 때마다 발생하는 데이터(예: ISBN, 처리 시간 등)를 변경할 수 없는 튜플(Tuple) 구조로 묶고, 이를 리스트(List)에 순차적으로 저장합니다. CLI 메뉴에는 '통계 조회' 기능을 추가하여, 저장된 이력 데이터를 바탕으로 월간 대여 통계나 가장 많이 대여된 도서 목록을 콘솔 화면에 출력하는 로직을 구현합니다. |
| **고급 예외 처리 및 유효성 검증** | 존재하지 않는 도서 반납 시도처럼 프로그램 실행 중 발생할 수 있는 예외 상황에 대응하는 예외 처리 구조를 구현합니다. 오류가 반복되지 않도록 처리 과정을 로그로 기록하거나 입력 단계에서 올바른 값만 받도록 유효성 검증 로직을 추가합니다. 아울러 디버깅을 통해 코드를 수정한 상세 내역을 주석 등으로 명확히 기록합니다. |

### 2️⃣ 결과물

#### 결과물 형식

> - 실행 가능한 파이썬 소스 코드 스크립트 및 패키지 구조 (`.py`)
> - 환경 설정 및 의존성 고정용 설정 파일 (`.toml`, `.lock`)

#### 결과물 위치

> 수강생 본인의 컴퓨터 로컬 저장소 내 독립된 프로젝트 루트 디렉터리에 위치해야 하며, 전체 디렉터리가 최상단에 고정된 형태의 단일 압축 파일(`.zip`) 상태로 LMS에 등록되어야 합니다.

## 📊 채점 기준표

### 개발 환경 구축 및 재현성 확보

`uv`로 격리 환경을 구축하고 VS Code에서 메인 스크립트 실행 성공 및 의존성 고정(lock) 환경 재현성을 명확히 보장할 수 있다.

### 객체지향 구조화

클래스·상속으로 요구 기능을 완전 구현하며 캡슐화/메서드 오버라이딩 등 OOP 설계 의도가 코드에 드러나고 가독성이 높다.

### 자료구조 기반 처리

목적에 맞는 자료구조를 정확히 선택해 저장·조회·가공을 완전 구현하며 선택 근거(성능/중복제거 등)를 주석으로 비교 설명할 수 있다.

### 제어 흐름 로직 및 대여/반납 구현

조건·반복 기반 검사/검색/집계/필터링(대여 및 반납 제어 포함)을 완전 구현하며 경계·예외 조건 처리 및 메뉴 제어 결과 검증까지 확인할 수 있다.

### 코드 추상화 및 모듈화

반복 로직을 함수·모듈·패키지 구조로 적절히 분리해 재사용성을 확보하며 매개변수/반환 설계 및 스코프 관리가 명확하고 가독성이 높다.

### 예외 방어 및 결함 진단

예외 처리를 적절히 적용하고 디버깅으로 원인을 정확히 진단·수정하며 예외 유형 구분과 재발 방지(검증 알고리즘/로그 출력)까지 반영할 수 있다.
